# 匠魂 · 制造业老师傅工艺知识库

> 老师傅会退休，经验要留下。

匠魂是一款面向 **50–500 人中小制造企业**的工艺知识库。它不卖通用文档工具，而是用「驻厂访谈 + 现场拍摄 + AI 结构化」，把老师傅脑子里的参数、异常处理和客户要求，变成新人问得到、查得准、学得会的答案。

这个仓库包含两部分：

- **产品项目书**：战略层完整立项文档（42 页，11 章 + 3 个附录）
- **可点击 MVP 原型**：6 个核心页面 + 角色切换，用来验证“采集—审核—问答—带教”的流程

## 原型演示路径

建议按这个顺序点一遍，5 分钟能看完：

1. **总览**：知识、提问、解决率、待审核、风险信号
2. **知识库**：工艺卡片 / 异常案例 / 老师傅问答，点卡片看条件、出处、版本
3. **问师傅**：答案带适用条件、出处、审核人、置信度
4. **采集工作台**：基本信息 → 模拟访谈 → AI 结构化 → 提交审核
5. **审核队列**：通过 / 退回；通过后知识库 +1
6. **新人路径**：7 天任务、进度环、班组进度
7. **设置**：角色权限、私有化、数据边界

右上角可切换 **厂长 / 老师傅 / 新人 / 班组长** 视角。

## 产品定义（一页纸）

| 要素 | 一句话 |
|---|---|
| 使用人群 | 50–500 人、至少 3 名老师傅、多品种小批量的注塑/五金/电子代工工厂 |
| 主要功能 | 工艺卡片、异常案例、老师傅问答、新人学习路径、版本管理 |
| 产品特色 | 驻厂采集 + 答案带适用条件 + 老师傅在环；不是通用文档库 |
| 商业价值 | 5–20 万元/年订阅 + 2–5 万元实施；ROI 约 8–10 倍 |
| 一句话 | 把老师傅脑子里的参数、异常和判断，变成新人能直接问的答案 |

## 建议的下一版

### 1. 后端 MVP

- FastAPI + PostgreSQL
- 表：`factory` / `user` / `process_card` / `anomaly_case` / `qa` / `source` / `review` / `version`
- 文件：访谈录音、现场照片存 MinIO / 本地对象存储
- 权限：JWT + RBAC（厂长 / 老师傅 / 新人 / 班组长）

### 2. AI 只做“候选”

```text
录音/照片 → ASR + OCR → LLM 按模板抽取
→ 生成候选字段 → 老师傅审核 → 发布
```

问答侧：

```text
问题 → 关键词 + 向量混合检索
→ 候选答案（带出处/条件/置信度）
→ 老师傅审核过的答案才返回
```

**不要让 AI 直接给最终工艺指令。** 尤其在压力、温度、化学品、特种设备相关工序。

### 3. 一个车间的试点

- 1 家工厂、1 个车间、3 位老师傅、50 条问答
- 8 周，先看“重复问师傅次数”和“新人上手时间”
- 不一开始做全厂、知识图谱、数字人
