# 匠魂 · 工艺知识库 MVP v0.1

一个用于验证「老师傅经验 → 可问、可查、可训练」流程的**可点击前端原型**。

它不是正式产品：没有后端、没有真实 AI、没有登录；数据是演示数据。但它把最关键的 6 个页面和 3 条主流程跑通了，适合拿来对齐产品形态。

---

## 直接看

**方式一：双击打开**

直接双击 `index.html`，用浏览器打开即可。所有资源都在本地，不需要联网。

**方式二：本地服务**

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory .
```

然后打开：<http://127.0.0.1:4173/>

> 当前会话里已经起了一个本地预览：<http://127.0.0.1:4173/>

## 演示路径

建议按这个顺序点一遍，5 分钟能看完：

1. **总览**：看“知识、提问、解决率、待审核”四个数，以及今天的三个风险信号。
2. **知识库**：切“工艺卡片 / 异常案例 / 老师傅问答”，点任意卡片看适用条件、出处、版本。
3. **问师傅**：直接点“PA66-GF30 夜班尺寸超差怎么调？”，看答案卡如何带条件、出处、审核人、置信度。
4. **采集工作台**：点“下一步 → 模拟一段访谈 → AI 结构化”，看一条经验如何被整理成 7 个字段，再提交审核。
5. **审核队列**：点“通过并发布”，看知识库 +1、待审核 -1；点“退回补充”看另一条路径。
6. **新人路径**：勾选任务，看进度环变化；右上角切“新人”视角，看导航变化。

右上角的“视角”可以切换：

- **厂长**：看结果、ROI、审核队列
- **老师傅**：看采集、审核
- **新人**：看问答、学习路径
- **班组长**：看新人进度、交接

## 现在是真的 / 现在是模拟的

| 部分 | 状态 |
|---|---|
| 页面结构、导航、角色切换 | 真的 |
| 知识库筛选、搜索、详情抽屉 | 真的 |
| 问师傅：关键词匹配 + 答案卡 | 真的（规则匹配，不是大模型） |
| 采集：模拟访谈、AI 结构化、提交审核 | 真的（前端状态变化） |
| 审核：通过/退回、知识库 +1 | 真的（仅当前页面状态） |
| 数据持久化 | 没有，刷新即重置 |
| 登录、权限、私有化部署 | 没有，只有前端角色演示 |
| 真实 ASR / LLM / 向量检索 | 没有，下一版接 |

## 建议的下一版

### 1. 先把“一条知识”做成真的

- FastAPI + PostgreSQL
- 表：`factory` / `user` / `process_card` / `anomaly_case` / `qa` / `source` / `review` / `version`
- 文件：访谈录音、现场照片存 MinIO / 本地对象存储
- 权限：JWT + RBAC（厂长/老师傅/新人/班组长）

### 2. 再接 AI，但只做“候选”

```text
录音/照片 → ASR + OCR → LLM 按模板抽取
→ 生成候选字段 → 老师傅审核 → 发布
```

问答侧：

```text
问题 → 关键词 + 向量混合检索
→ 候选答案（带出处/条件/置信度）
→ 老师傅审核过的答案才返回
```

**不要让 AI 直接给最终工艺指令。** 尤其在压力、温度、化学品、特种设备相关工序。

### 3. 再做一个车间的试点

- 1 家工厂、1 个车间、3 位老师傅、50 条问答
- 8 周，先看“重复问师傅次数”和“新人上手时间”
- 不要一上来做全厂、知识图谱、数字人
